# Superstore Sales Dashboard (Python + Looker Studio)

## Overview

This project simulates a real-world business intelligence dashboard built from retail sales data.

The goal was to transform raw transaction data into executive-level reporting that supports decision-making.

Python (pandas) was used for data preparation, and Looker Studio was used for visualization.

---

## Business Questions Answered

• Which product categories drive the most revenue?  
• Which regions generate the highest profit?  
• How do monthly sales trends change over time?  
• What are the executive KPIs for leadership reporting?

---

## Key Insights

- Technology leads total revenue across all categories
- Western region generates the highest profit margin
- Sales show consistent seasonal spikes in Q4
- Growth trend increases steadily year-over-year
